| 项 | 值 |
|---|---|

> 定位：W1 交付**画布设施**（视口、坐标、渲染、失效调度）；W2 把内置 Agent 的 turn 抽象包装成**内置画布预设**，并给出「卡片在画布上怎么安放」的规则表。连线只做**只读呈现**——它不是接线，后端编排模型（`WorkflowNode` / 交接类别 / 模板命令）尚未接入，所以「不能改」不是权限开关，而是数据缺席（§6.1）。

本文中的「必须 / 禁止」为可验收约束；「应当」为默认做法，偏离需在代码注释里写明理由。

## 1 范围与边界

### 1.1 交付什么

| # | 目标 | 判据 |
|---|---|---|
| 1 | 预设实体：标识（id / 名称键 / 说明键）+ 卡片来源 + 区带命名 + 连线策略 | A1 / A2 / A12 |
| 2 | 预设摆放：区带 + 模板列位 → 盒子，纯函数、零测量 | A6 / A7 / A8 |
| 3 | 只读连线：12 条边全部呈现，端点落在卡片边框锚点，不可聚焦、无命中区 | A5 / A10 / A11 |
| 4 | 预设标识可见：头信息行显示预设名 + 「内置 · 只读」，并说明为何不可编辑 | A13 |
| 5 | 术语闭环：预设 / 区带 / 摆放 / 只读连线全部对齐词表，L2 词零出现 | A14 |

### 1.2 不交付什么

| # | 排除项 | 理由 |
|---|---|---|
| 1 | 连线编辑：拖拽连线、断开、删除、插入卡片 | 后端 L2 未接入，四条硬条件全缺（§6.1） |
| 2 | 端口 / 槽 / 连接句柄 / 悬空接线 | 端口 = 视觉锚点 + 命中区 + 类型声明三合一（词表 §2.5.2）；W2 只有第一项，不得叫端口 |
| 3 | 卡片拖拽重排 / 吸附 / 对齐辅助线 | 需写坐标回模板，模板是 L2 数据；W2 的坐标是派生量（§4.4） |
| 4 | 用户预设：新建 / 导入 / 导出 / 重命名 | 需 schema + 版本 + 持久化，属 L2 范畴 |
| 5 | 多预设并置或切换 | W2 只有一份内置画布预设（OQ-2） |
| 6 | 容器卡片 / 嵌套子图 | 词表标「先占名、未立项」；12 张卡片平铺在同一画布 |
| 7 | 预设绑定内置模式（模型 / 工具 / 审批） | 预设只描述**摆放**，不描述运行配置（§2.5 易混词表 / OQ-1） |
| 8 | 自动布局（dagre / 力导向）与自动 fit | 12 张卡片不需要图算法；自动 fit 需测量（W1 §1.2 第 9 条） |
| 9 | 卡片内容自适应宽度 | 内容决定几何 → 需测量，违反 N3 |

### 1.3 与 W1 的关系

| 层 | W1 交付 | W2 增量 |
|---|---|---|
| 视口 | `CanvasViewport`：视口、缩放、平移 | 不改 |
| 几何 | `layoutTemplate(entries)`：模板 → 盒子 | 新增 `layoutPreset(preset)` 作为**唯一布局入口**，内部仍调用 `layoutTemplate`（公式只有一份） |
| 渲染 | `CanvasCard` / `CanvasEdge` / `CanvasLegend` | `CanvasEdge` 端点改由锚点推导并显式只读；新增 `CanvasPresetBadge` |
| 内容 | 12 张卡片 + 12 条边 + 出口，来源是模板常量 | 内容来源改为**预设**（预设引用模板，不复制） |
| 调度 | `subscribeProjections` 帧合并 | 不改；预设与投影正交 |

**单向派生链**（不得反向）：

```
turn 模板（AGENT_NODE_TEMPLATE / TEMPLATE_EDGES）
        │ 被引用（不复制）
        ▼
内置画布预设（preset：区带命名 + 卡片来源 + 只读连线策略）
        │ layoutPreset()
        ▼
盒子（CanvasBox：x / y / w / h） ── 常量，模块加载时算一次
        │
        ▼
卡片 / 连线 / 区带标签（DOM）
```

### 1.4 与词表的差异（有意校正，登记见 §15）

| # | 词表表述 | 本规格 | 理由 |
|---|---|---|---|
| D-1 | §2.5.2 原无「预设」；该词被旧文档用作「内置模式」的别称 | 收回「预设」为**画布预设**（命名）；旧称改判**内置模式** | 内置 Agent 抽象需要一个画布侧的名字，且必须与「模板」「内置模式」区分（§2.5 易混词表 / T-11） |
| D-2 | §2.5.3 锚点是「格子边缘的纯几何锚定位置」 | 锚点同样用于**画布卡片边缘** | 纯几何、不承载类型、不可连接，定义完全同构；只是所在画布不同（T-15） |
| D-3 | §2.5.2 连线 = 接线的渲染形态 | 连线可以**没有**对应接线（只读呈现） | W2 无交接类别，连线只是模板边的像素形态（T-14） |
| D-4 | §2.5.2 工具分支（tool lane） | **工具分支区带** | 「区带」是摆放层的限定词，指世界坐标的行分区（T-12） |

### 2.2 新增术语（词表 §2.5.2 已登记，性质：命名）

| 术语 | 英文 | 定义 | 为什么需要 |
|---|---|---|---|
| **画布预设** | canvas preset | 画布上的一组**预置呈现方案**：卡片来源 + 区带命名 + 连线策略 + 文案标识；不含坐标、不含参数 | 内置 Agent 抽象在画布上需要一个可命名的整体；「图」「模板」都已被占用（§2.5 易混词表） |
| **内置画布预设** | built-in canvas preset | 随应用发布的画布预设（编译期常量，`builtin: true`）；与「用户预设」（未立项）相对 | 区分「代码内置」与「用户创建」 |
| **预设摆放** | preset placement | 把预设的卡片按区带与列位换算成世界坐标盒子的过程；原语 `layoutPreset` | 用户词「摆放」↔ 原语 `layoutPreset`，成对给出（词表 §2.6.7 第 4 条） |
| **区带** | zone | 世界坐标的行语义分区；一个区带承载一组卡片，并有一个说明标签 | 摆放需要「行 = 什么含义」的名字，不能只说 row 0 / row 1 |
| **主链区带** | main lane | 第一行区带：turn 内部阶段按顺序从左到右 | 与「工具分支区带」并列，构词对称（T-12） |
| **工具分支区带** | tool lane zone | 第二行区带：⑦ 判定后按条件进入的 ⑧–⑫ | 「条件进入」是区带语义，需要限定词（T-12） |
| **回边外轨** | loop rail | 顶部为回边让出的横向轨道（世界 `y ∈ [0, loopGutter)`） | 回边不走行间隙，需要独立命名（W1 §1.3 D-4） |
| **只读连线** | read-only connector | 连线的只读约束形态：无命中区、不可聚焦、无手势、无 hover / focus 样式 | 「只读」必须落在连线这一层，而不是笼统说「画布只读」 |
| **源锚点 / 目标锚点** | source anchor / target anchor | 连线两端落在卡片边框上的几何点（起端 / 终端） | 词表只有无方向的「锚点」；连线需要方向（T-15） |

### 2.3 用词纪律

| 禁止 | 应写 | 说明 |
|---|---|---|
| 「节点」 | 卡片 | 「节点」是原语词（`ObservationNode` / `WorkflowNode`），不是用户词（W1 §2.2） |
| 「执行体」「执行单元」 | （不出现） | 两者都是 L2 / 内核层概念；W2 的 12 张卡片是 turn 内部阶段，不引用执行单元（§2.4） |
| 「接线」 | 连线 / 边 | W2 无交接类别，没有类型化交接实例；「接线」只用于 L2 语义（§6.2 / T-14） |
| 「端口」 | 锚点 | 运行内容不可接，端口是 L2 概念 |
| 「内置预设」 | 内置模式 | 旧称指运行配置 seed（`builtin-agent` 等），与画布预设无关（词表 §2.5.4 / T-11） |
| 「预设」不加限定 | 画布预设 | 「预设」已收回给画布侧；本文正文的「预设」是「画布预设」的简称，代码符号 `preset` 不变 |
| 「节点模板」「模板」不加限定 | turn 模板 / 工作流模板 / 画布预设 | 三者不同层，命名混用是最大返工来源（词表 §2.5.4） |
| 「模式预设」「预设模式」 | 画布预设 / 内置模式 | 预设描述摆放，模式描述运行配置，不得拼成一个词 |
| 「布局」用于用户文案 | 摆放 | 用户词是「摆放」，代码原语是 `layoutPreset` / `CanvasLayout` |
| 「格子」「单元格」 | 卡片 / 盒子 | 本规格画的是画布，不是观测栅格（W1 §1.5 T-10） |
| 「容器」用于区分层级 | 画布 / 观测栅格 / 容器卡片 | 「容器」是描述词不是术语（词表 §2.5.4）；DOM 承载盒可称容器，但不作层级名 |
| 「连线可拖拽」「连线中」 | （不出现） | 「连线中」是手势状态，W2 无手势 |

### 2.4 不出现的 L2 词（不是漏写，是 W2 不交付）

| 词 | 词表定义 | 为何 W2 不出现 |
|---|---|---|
| 执行卡片 execution card | 引用一个执行单元的卡片，`WorkflowNode` 主类别 | 无工作流模板，无 `WorkflowNode` |
| 容器卡片 container card | 承载子图的卡片，先占名、未立项 | 不渲染嵌套子图 |
| 执行单元 execution unit | 被 `WorkflowNode` 引用的实体 | 无引用关系 |
| 卡片类别 card kind | 执行卡片按执行单元分型，闭集未定案 | 未定案，不得预设 |
| 端口 / 输出槽 / 输入槽 | 可连接位置 + 命中区 + 类型声明 | 运行内容不可接 |
| 接线 / 交接类别 / 连接句柄 | 类型化交接实例及其端点 id | 交接类别未定案（编排分析 §12.2 #1 标「缺，最关键」） |
| 参数 / 参数 schema / 参数表单 / 参数项 / 参数摘要 | 用户填的常量配置及其定义与控件 | 编辑模式才需要；W2 只有运行模式 |
| 编辑模式 / 插入点 / 连线中 / 悬空接线 / 就绪集合 / 激活 / 冲突域 | 编排编辑与调度语义 | 无编辑、无调度 |

### 2.5 易混词：画布预设 / 模板 / 模式

| 概念 | 是什么 | 数据位置 | 谁可改 | W2 是否出现 |
|---|---|---|---|---|
| **画布预设** | 画布呈现方案（卡片来源 + 区带命名 + 连线策略 + 文案） | 前端编译期常量 | 代码（用户不可改） | 是（唯一一份） |
| **turn 模板** | L1 观测拓扑：12 条模板条目的 `order` / `row` / `column` | 前端编译期常量 | 代码 | 是（作为画布预设的卡片来源） |
| **工作流模板** | L2 可编辑图：`WorkflowNode` + 参数 + 类型化交接 | 后端存储 | 用户 | 否（未立项） |
| **内置模式** | 运行配置：模型 / 工具 / 审批等级（旧称「内置预设」） | 后端存储 | 用户 | 否（与摆放无关） |

一句话：**画布预设回答「卡片怎么摆」，模板回答「卡片有哪些、谁接谁」，内置模式回答「跑起来用什么」**。三者不可互换，也不可拼词。

## 4 预设模型

### 4.1 预设是什么 / 不是什么

| 判定 | 结论 | 依据 |
|---|---|---|
| 是画布内容的呈现方案吗 | 是 | 本规格 §4.2 |
| 是可编辑图吗 | 不是 | 无 `WorkflowNode`、无参数、无交接类别 |
| 是模板吗 | 不是 | 预设引用模板，不复制；模板是拓扑，预设是呈现 |
| 是运行配置吗 | 不是 | 不含模型 / 工具 / 审批 |
| 存坐标吗 | 不存 | 坐标是派生量（§4.4） |
| 可序列化吗 | 可（结构是纯数据常量），但 W2 不做导入导出 | OQ-3 |

### 4.2 三件构成

| 件 | 内容 | 不变量 |
|---|---|---|
| **标识** | `id`、`titleKey`、`descriptionKey`、`builtin: true` | 文案只走 i18n；`builtin` 是字面量类型 |
| **内容** | 卡片清单（引用模板条目 id）+ 区带表（行号 + 说明键 + 留白列） | 不复制 `row` / `column` / 边集 |
| **策略** | 连线只读（`source: "template-edges"`、`editable: false`） | 连线集合唯一来源是 `TEMPLATE_EDGES` |

### 4.3 类型定义（`src/features/canvas/presets/types.ts`）

```ts
import type { AgentNodeId } from "@/stores/agent/observation/types";
import type { TemplateEdgeKind } from "@/stores/agent/observation/template";

export type CanvasPresetId = "builtin-agent-turn";

export type CanvasZoneId = "main-lane" | "tool-lane";

/** 区带：世界坐标的行语义分区。row 与模板 row 一致（A3 断言）。 */
export interface CanvasZone {
  id: CanvasZoneId;
  /** 世界坐标行号，来自 turn 模板的 row。 */
  row: number;
  /** 区带说明文案的 i18n 键。 */
  labelKey: string;
  /**
   * 区带内留给说明标签的列号（含端点）；`null` 表示整行都是卡片、无标签。
   * 只用于标签定位，不参与盒子几何。
   */
  labelColumns: readonly number[] | null;
}

/** 预设中的一张卡片：只声明区带归属，不声明坐标与列位。 */
export interface PresetCard {
  /** 模板条目 id（`AgentNodeId`，原语词，不作为用户文案）。 */
  nodeId: AgentNodeId;
  zone: CanvasZoneId;
}

/** 连线策略：连线集合由模板边集派生，预设不复制边集。 */
export interface PresetConnectorPolicy {
  source: "template-edges";
  /**
   * 只读：无命中区、不可聚焦、不可编辑、不可删除。
   * L2 后端接入后才允许出现 `true`（§6.6）。
   */
  editable: false;
}

export interface CanvasPreset {
  id: CanvasPresetId;
  builtin: true;
  titleKey: string;
  descriptionKey: string;
  zones: readonly CanvasZone[];
  cards: readonly PresetCard[];
  connectors: PresetConnectorPolicy;
}

/** 布局入口：预设 + 常量 → 盒子（无 DOM、无视口）。 */
export function layoutPreset(preset: CanvasPreset): CanvasLayout;
```

`layoutPreset` 的实现必须是「预设 → 模板形态 → W1 的 `layoutTemplate`」两步，**不得**另写一套坐标公式：

```ts
export function layoutPreset(preset: CanvasPreset): CanvasLayout {
  const rowByZone = new Map(preset.zones.map((zone) => [zone.id, zone.row]));
  const entries = preset.cards.map((card) => ({
    id: card.nodeId,
    row: rowByZone.get(card.zone) ?? 0,
    column: templateColumnOf(card.nodeId),
  }));
  return layoutTemplate(entries);
}
```

`templateColumnOf(nodeId)` 是 `AGENT_NODE_TEMPLATE` 的一次 `Map` 查表（列位的唯一来源是模板，预设不复制）；`layoutTemplate` 是 W1 §5.5 的几何函数，W2 不改它的公式。

### 4.4 预设不存坐标（四条理由）

| 理由 | 后果（若存坐标） |
|---|---|
| 坐标是 `CANVAS_METRICS` + 模板列位的派生量 | 改 `cellW` / `gap` 后旧坐标错位，出现两套几何 |
| W2 无编辑，坐标不会被用户改写 | 存了也没有写入方，只增加漂移面 |
| 预设要可校验（A3 / A8 / A9） | 坐标无法与模板做一致性断言 |
| L2 的坐标归工作流模板（用户拖拽结果） | 前端存一份会让「谁是真值」变成两处 |

### 4.5 不可变性与编译期锁

- 预设常量必须 `Object.freeze`（深冻结到 `zones` / `cards` 数组），运行时只读。
- `cards` 用 `satisfies readonly PresetCard[]` 且由 `AGENT_NODE_IDS` 映射生成，保证：模板增删卡片时预设**编译失败**而不是静默漏一张（A1 / A2）。
- 预设不得含函数、不得含坐标、不得含 i18n 译文（只有键）。

## 5 摆放模型（核心）

### 5.1 三层分离

| 层 | 产物 | 谁产生 | 可否读 DOM |
|---|---|---|---|
| 拓扑层 | 模板：`order` / `row` / `column` | 编译期常量 | 否 |
| 摆放层 | 盒子：`x` / `y` / `w` / `h` + 区带归属 | `layoutPreset()` 纯函数 | 否 |
| 渲染层 | 卡片 / 连线 / 区带标签的 DOM | `CanvasCard` / `CanvasEdge` | 否（几何全部来自摆放层） |

**分层纪律**：区带归属只属于摆放层；卡片组件不得自己判断「我在第几行」，否则同一语义出现两处实现。

### 5.2 区带

世界坐标（`cellW = 132`、`cellH = 78`、`gap = 8`、`loopGutter = 16`，均来自 W1 §5.5）：

| 区带 | 行 | 世界 `y` 范围 | 卡片 | 说明 |
|---|---|---|---|---|
| **回边外轨** loop rail | — | `[0, 16)` | 无（只走 ⑫→① 回边） | 为闭环让出的顶部轨道 |
| **主链区带** main lane | `row 0` | `[24, 102)` | ①–⑦（7 张） | 顺序 = 阶段顺序，从左到右 |
| **工具分支区带** tool lane | `row 1` | `[110, 188)` | ⑧–⑫（5 张） | 条件进入，不代表时间先后 |
| **出口角标** exit corner | — | 卡片内右下角 | 无（汇点） | 出口不是卡片、不占轨道 |

区带与卡片归属：

| 区带 | 卡片 | 列位（来自模板 `column`） |
|---|---|---|
| 主链区带 | ① 准入 ② 快照+投影 ③ 刹车 ④ 上下文阶梯 ⑤ 模型调用 ⑥ assistant 行落库 ⑦ 判定 | 0 – 6 |
| 工具分支区带 | ⑧ 预算切分 ⑨ 工具流水线 ⑩ 工具后中间件 ⑪ 工具结果落库 ⑫ 迭代尾 | 6 – 10 |

**工具分支区带的留白**：列 0–5 无卡片，留给区带说明标签（`observation.graph.tool_lane`，长句即区带说明，不新增短键）。留白是**几何事实**（`labelColumns = [0,1,2,3,4,5]`），不是「空卡片」。

### 5.3 摆放规则

| # | 规则 | 判定方式 |
|---|---|---|
| P1 | 一区带一行：区带之间不折行、不混排；卡片行号恒等于所属区带的 `row` | A3 / A4 |
| P2 | 列位来自模板：卡片 `x` 只由模板 `column` 决定，同一列跨行对齐（⑦ 与 ⑧ 同为 `column 6`） | A9 |
| P3 | 等距：列间距 = 行间距 = `gap`；卡片宽高恒定，不随文案长度变化 | A8 |
| P4 | 顶部留轨：第一行 `y` 起点 = `loopGutter + gap`，回边外轨独占上方 | A9 |
| P5 | 左起原点：`x` 原点 = 0，最左卡片贴世界左边界；不做水平居中 | A9 |
| P6 | 留白不画：区带 `labelColumns` 范围内不出现卡片，只出现区带标签 | A4 |
| P7 | 出口内嵌：出口落在终态卡片内部，不占轨道、不改几何 | A9 |
| P8 | 零测量：摆放只吃预设 + `CANVAS_METRICS`；同一预设在任何视口尺寸下产出同一坐标 | A6 / A7 |

### 5.4 坐标公式

**唯一公式在 W1 §5.5，本规格只做输入替换**：

| 项 | 公式 |
|---|---|
| `x` | `column * (cellW + gap)` |
| `y` | `loopGutter + gap + row * (cellH + gap)` |
| `w` / `h` | `cellW` / `cellH` |
| 世界宽 | `(maxColumn + 1) * cellW + maxColumn * gap` = `11 * 132 + 10 * 8` = `1532` |
| 世界高 | `loopGutter + gap + (maxRow + 1) * cellH + maxRow * gap` = `16 + 8 + 2 * 78 + 8` = `188` |

`layoutPreset` 的输出必须与「把模板原样交给 `layoutTemplate`」的结果**深相等**（A9）——预设只换区带命名，不改几何。

### 5.5 摆放不变量

| # | 不变量 | 断言方式 |
|---|---|---|
| N1 | 盒子两两不相交（矩形不重叠） | A8 |
| N2 | 连线端点落在盒子边框（不越入盒内） | A10 |
| N3 | 摆放函数签名不含 DOM / 视口参数 | A6 |
| N4 | 世界尺寸 = 盒子包围盒（除 `loopGutter` 外不加边距） | A9 |
| N5 | 每张卡片恰好属于一个区带；区带由预设声明，不由顺序推断 | A4 |
| N6 | 出口不参与几何：有无出口，盒子坐标不变 | A9 |
| N7 | 预设不含坐标字段（类型层面无 `x` / `y` / `w` / `h`） | A12 |

### 5.6 为什么这样摆（读图约定）

| 摆放选择 | 表达的语义 | 替代方案为何不行 |
|---|---|---|
| 横向 = 时间轴（`order` 递增从左到右） | 阅读方向 = 执行方向 | 纵向时间轴会让 11 列变成 11 行，视口高度失控 |
| 纵向 = 分支（工具分支换行） | 「条件进入」而非「时间先后」 | 混在同一行会让 ⑧ 看起来紧跟 ⑦ 必然发生 |
| 回边走顶部外轨 | 闭环 = 回到起点 | 走行间隙会横穿 11 列（W1 §1.3 D-4） |
| 出口内嵌右下角 | 终点是「从这张卡片离开」，不占位 | 出口独立成卡片会污染边集与焦点序列（W1 §1.3 D-3） |
| 工具分支左侧留白 + 区带标签 | 留白有语义（「仅当 ⑦ 判定需要工具」） | 空白无标签会被读成「漏了 6 张卡片」 |

## 6 只读连线

### 6.1 为什么不能改（数据缺席，不是权限开关）

| # | 缺什么 | 缺了会怎样 |
|---|---|---|
| 1 | `WorkflowNode` 数据模型 | 没有「这条线连的是谁」的实体，改边无处落库 |
| 2 | 交接类别闭集（未定案） | 连线没有类型，保存期校验（O13）无法判定合法性 |
| 3 | 模板命令通道（新建 / 改边 / 删边 + 契约） | 前端改了也发不出去 |
| 4 | 模板版本 / 冻结快照 | 改了无法追溯，也无法回滚 |

**结论**：W2 的连线是「模板边的像素形态」，不是可编辑的接线。等 L2 接入后，`PresetConnectorPolicy.editable` 才允许出现 `true`（§6.6）。

### 6.2 连线 / 接线 / 边三层区分

| 层 | 是什么 | W2 是否有 |
|---|---|---|
| 语义 | 接线（wiring）：两个交接端点之间的类型化交接实例 | 无（交接类别未定案） |
| 数据 | 边（edge）：`from` / `to` / `kind`（`GraphEdgeView`，无 id、无句柄、无标签） | 有（12 条，来自 `TEMPLATE_EDGES`） |
| 渲染 | 连线（connector）：路径 + 状态，W2 无命中区 | 有（12 条，只读） |

**一句话**：W2 有**边**和**连线**，没有**接线**。所以本规格一律写「连线」，禁止写「接线」（T-14）。

### 6.3 端点 = 锚点，不是端口

| 概念 | 构成 | W2 |
|---|---|---|
| 端口 port | 视觉锚点 + 命中区 + 类型声明 | 三缺二，不得使用 |
| 锚点 anchor | 纯几何位置，不承载类型、不可连接 | 使用（源锚点 / 目标锚点） |

锚点推导（原语 `anchorOf(box, side)`，词表 §2.6.5 已规划，W2 落地为画布版本）：

| 锚点 | 位置 |
|---|---|
| 源锚点（右侧） | `x = box.x + box.w`，`y = box.y + box.h / 2` |
| 目标锚点（左侧） | `x = box.x`，`y = box.y + box.h / 2` |
| 源锚点（下侧，⑦→⑧） | `x = box.x + box.w / 2`，`y = box.y + box.h` |
| 目标锚点（上侧，⑦→⑧） | `x = box.x + box.w / 2`，`y = box.y` |
| 回边起端（⑫ 右侧） | `x = ⑫.x + ⑫.w`，`y = ⑫.y + ⑫.h / 2` |
| 回边终端（① 左上角） | `x = ①.x`，`y = ①.y`（左竖段沿 ① 左边缘上行，箭头在顶横左端） |

纪律：锚点只由盒子推出，**不读 DOM**；不画端口桩（桩会暗示可连线，W1 §1.3 D-5）。

### 6.4 只读约束

| # | 约束 | 实现 |
|---|---|---|
| R1 | 无命中区 | 连线层 `pointer-events: none` |
| R2 | 不进入焦点序列 | 无 `tabindex`、非 `button`、非 `a` |
| R3 | 无 hover / focus / active 样式 | 无对应选择器；状态只由相位决定 |
| R4 | 无光标变化 | 不出现 `crosshair` / `grab` / `grabbing` |
| R5 | 无端点手柄 | 不画端口桩、不画悬空短桩、不画「+」插入点 |
| R6 | 不可删除 / 不可插入 | 无右键菜单、无 Delete 处理、无「插入点」 |

**相位不是编辑**：连线的四相（`untaken` / `idle` / `passed` / `active`）由投影推出，属于观测，不属于编辑；只读连线仍然可以有相位与活动边动画（W1 §7）。

### 6.5 连线几何

几何沿用 W1 §6.4（10 条同行 + 1 条跨行 + 回边三段 + 1 个箭头 = 15 个元素），W2 只改两点：

| 改动 | 从 | 到 |
|---|---|---|
| 端点来源 | 盒子边缘偏移量（`from.x + from.w`） | `anchorOf(box, side)` 显式锚点（A10） |
| 只读声明 | 隐式（W1 未画手势） | 显式（`pointer-events: none` + 无 `tabindex`，A11） |

### 6.6 后端接入后的变更点（预留，不在 W2 交付）

| 变更 | 触发条件 |
|---|---|
| `PresetConnectorPolicy.editable` 由 `false` 改为 `boolean` | L2 模板命令通道落地 |
| 连线增加命中区与选中态 | 需要「选中一条连线」的产品语义（OQ-4） |
| 端点由锚点升级为端口 | 交接类别闭集定案（编排分析 §12.2 #1） |
| 卡片出现拖拽柄与参数区 | 编辑模式立项（W1 §1.2 第 1 条） |

## 7 卡片呈现

### 7.1 卡片模式

W2 只有一种卡片模式组合：**运行模式 × 概览**（主体 = 运行摘要）。理由：预设只读，无编辑模式；卡片尺寸固定，无详情态（缩放详情属 W1 §11 的视口行为，不由预设决定）。

| 维度 | 取值 | 说明 |
|---|---|---|
| 卡片模式 | 运行模式 | 不渲染参数表单（无参数） |
| 缩放级别 | 概览 | 主体 = 状态 + 名称 + 序号 + 证据徽标 |

### 7.2 卡片构成（W2 只渲染三件）

| 件 | 渲染 | 依据 |
|---|---|---|
| 名称 + 序号 | 是（`observation.node.*`） | 词表 §2.5.1 单元格构成 |
| 状态 + 证据徽标 | 是（`observation.state.*` / `observation.source.*`） | 同上 |
| 出口角标 | 终态卡片内右下角 | W1 §6.5 |
| 端口区 / 拖拽柄 / 参数表单 / 脚部 | 否 | 属 L2 编辑语义（§2.4） |

### 7.3 卡片与区带的解耦

卡片组件不得知道区带，也不得知道行号：它只接收盒子与视图数据。区带信息只用于**区带标签**（`CanvasZoneLabel`，位置来自 `labelColumns` + `row`），避免「卡片自己判断自己在哪一行」这种双实现。

## 9 失效调度与性能

| 项 | 结论 |
|---|---|
| 预设常量 | 模块加载时构造一次，深冻结；不随事件流重建 |
| 布局结果 | `layoutPreset` 结果在模块加载时算一次（预设是常量），视口变化不重算（只改 `transform`） |
| 连线 | `CanvasEdge` 必须 `React.memo`，props 只有几何 + 相位（W1 §11.5） |
| 预设标识 | 静态文本，不订阅投影，不参与每帧重渲染 |
| 禁止 | 在预设里放函数 / 放 getter / 每次渲染新建数组（会让 memo 全失效） |

## 13 已拒绝方案

| # | 方案 | 拒绝理由 |
|---|---|---|
| R1 | 预设存坐标（`x` / `y` / `w` / `h`） | 与 `CANVAS_METRICS` 形成两套几何（§4.4） |
| R2 | 预设从 JSON 运行时加载 | 需 IO + 校验 + 版本，W2 内置常量足够 |
| R3 | 预设直接等于工作流模板 | 需 L2 schema、参数、交接类别；会把未立项的形状塞进前端 |
| R4 | 预设复制边集 | 与 `TEMPLATE_EDGES` 漂移，出现「高亮的边不在边集里」（W1 §5.1） |
| R5 | 连线可拖拽预览（松手回弹） | 暗示可编辑，且需要命中区与手势状态（§6.4 R1 / R5） |
| R6 | 卡片内容自适应宽度 | 内容决定几何 → 需测量（N3） |
| R7 | 预设绑定内置模式 id | 预设描述摆放，模式描述运行配置；绑定会把两层耦合（OQ-1） |
| R8 | 用 CSS Grid 摆放卡片 | 无法缩放 / 平移（W1 §1.3 D-1） |
| R9 | 引入 dagre 自动布局 | 12 张卡片不需要图算法，且会带入第二套坐标系（W1 §1.2 第 6 条） |
| R10 | 把出口画成第 13 张卡片 | 出口是汇点不是卡片（W1 §1.3 D-3 / N6） |
